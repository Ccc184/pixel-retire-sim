# 像素退休模拟器 (Pixel Retire Sim)

一款**赛博朋克像素风格**的人生模拟网页游戏。玩家从设定的起始年龄（默认 22 岁，可自定义）初入社会开始，选择一条"提前退休"的人生路径，通过每年一次的关键决策走完一生，最终在退休时结算一生的成败。

### 目标用户

面向 **20-35 岁、对"提前退休/财务自由"有真实焦虑或向往的都市职场人**。核心价值主张是"用 10 分钟预演你提前退休的每一种可能"——玩家可输入自己的真实起始年龄，游戏就从那一刻开始推演，帮助玩家在娱乐中审视自己的财务路径与生活方式选择。

核心隐喻：**人生就是一场抽卡游戏，你无法决定发到手里的牌，但可以决定怎么打出去。**

> 本文档描述当前版本（Demo v0.0.0）的实际实现，供 AI 与开发者快速理解项目全貌，不包含历史改动记录。

---

## 一、项目简介

游戏让玩家从设定的起始年龄（默认 22 岁）开始，在多达六条截然不同的"提前退休"路径中选择其一，逐年做出关键决策，最终走向自己的退休结局。它不是传统的数值堆砌模拟器，而是**以叙事为核心、以路径为骨架**的人生推演：每条路径代表对"未来 50 年世界走向"的一个赌注——赌对了提前自由，赌错了中途归零。

游戏强调**选择的分量**与**叙事连贯性**：年度结算最显眼的位置展示的是"你因为选择而触发的剧情"，而非冰冷的数字列表；结局画面会生成一张可分享的"年度人生报告"海报。

## 二、开局流程

游戏分两步开局：先选**人生路径**，再完成**人物配置**。

### 1. 选择人生路径（PathSelect）

标题为"你打算怎么提前退休？"，呈现 6 张路径卡，每张卡都代表一个对未来世界走向的赌注（详见下文"六条人生路径"）。文案强调每一条路都有不同的中期崩塌与结局，没有对错之分。

### 2. 人物配置（GameSetup）

- **一键开局·人生模板**：4 套预设人设（体制稳赢 / 高薪卷王 / 自由浪人 / 躺平极简），一键填好全部选项并开局；另有"随机人生"（命运洗牌）。
- **城市（3 可选）**：资本修罗场（高成本·机会多·裁员+5%）、中坚大后方（基准线·稳中求进）、避风低洼地（低成本·裁员-50%）。切换城市会联动推荐目标资产。
- **职业（6 可选）**：体制内、红利行业、传统私企、自由职业、实体创业、一线蓝领——各有独立的涨薪率、薪资上限与"35 岁断崖"等特性。
- **人格底色（可选彩蛋）**：4 种气质（NT / NF / SJ / SP），只影响叙事语气与轻微薪资修正，不选不影响。
- **退休梦想（必选）**：6 个梦想决定目标资产与结局趣味结算。
- **数值输入**：初始月薪（1 千~100 万）、目标退休资产。玩家输入的就是所选城市的实际月薪，城市差异体现在生活成本与裁员率上。

## 三、六条人生路径

每条路径包含：初始效果、卡牌权重、3 个专属「命运岔路口」（危机事件）、按年龄段的年度独白、信念动摇独白、成功/失败判定与结局、目标退休年龄。

| 路径 ID | 名称 | 图标 | 赌注（定位） |
|---|---|---|---|
| `ai_symbiote` | **AI 共生者** | 🤖 | 赌自己是驾驭浪潮的人。副业 → All In AI 产品；经历 28 岁技能贬值、32 岁 All In、35 岁伦理困境 |
| `chain_native` | **链上原住民** | ⛓️ | 信数学不信人，赌账本不会归零。拿部分存款购初始仓位；经历 27 岁交易所暴雷、30 岁深熊、33 岁监管铁拳 |
| `digital_nomad` | **数字游牧民** | 🎒 | 赌哪里便宜哪里就是家。远程工作锚定发达市场薪资，搬家不降薪（地理套利） |
| `super_ip` | **超级IP** | 📣 | 赌自己的名字比任何 Logo 值钱，把自己活成一个品牌 |
| `silver_economy` | **银发守夜人** | 🛎️ | 霓虹照不到的角落，守着养老 / 银发经济这盏灯 |
| `bio_gambler` | **生物赌徒** | 🧬 | 赌死亡是个能被黑掉的 Bug，活得久才是终极杠杆（生物科技组合） |

**通用机制**：每条路径初始设 `pathFaith = 35`（信念值），需长期积累并经重大考验才可能达到 All In 阈值（95）；`targetAge` 统一为 60（不强制提前退休年龄）。

## 四、年度核心循环

```
年初 → 抽取叙事事件/岔路口/日常 → 应用涨薪与职场意外 → 年度结算 → 更新身心与关系 → 展示年度结算面板 → 检查结局 → 年龄+1 → 下一年
```

核心动作 `commitYear()` 每年执行：

1. 记录年初基准（存款 / 压力 / 幸福 / 健康 / 技能等）。
2. 抽取当年**叙事事件**、**命运岔路口**与日常事件。
3. 应用涨薪、职场意外、年度结算（工资 + 副业 + 投资增益 - 生活支出 - 房贷 - 保险 = 净变化）。
4. 更新压力 / 幸福 / 健康及关系（恋爱、子女、父母、朋友）。
5. 生成年度日志与三分镜场景（家庭 / 生活 / 事业）。
6. 展示 **YearEndPanel** 年度结算面板，并由 `checkEnding` 判断是否触发结局。

**年度结算面板**：最显眼位置优先展示"选择引发的剧情"（叙事主线），下方以橙色区块展示当年度核心决策与身心数值变化；若当年有命运岔路口，则以独立分栏展示"⚡ 命运岔路口 · 你的抉择"。

## 五、数值体系

### 核心三项状态（0-100）

| 数值 | 说明 | 降到 0 的后果 |
|---|---|---|
| 压力 (Stress) | 工作、生活、负面事件叠加 | 精神崩溃 → 强制住院 → 花费巨大 |
| 幸福感 (Happiness) | 正面事件、成就、关系的满足 | 抑郁 → 无法工作 → 收入归零 |
| 健康值 (Health) | 年龄自然衰减 + 事件影响 | 中道崩殂 → 提前结束游戏 |

### 城市系数（`CITY_CONFIGS`）

| 城市 | costMultiplier | salaryMultiplier | layoffModifier |
|---|---|---|---|
| 资本修罗场 | 1.8 | 1.4 | +5% |
| 中坚大后方 | 1.0 | 1.0 | 基准 |
| 避风低洼地 | 0.4 | 0.55 | -50% |

### 薪资系统（核心引擎）

- **打工阶段**：基准年涨幅按职业设定（如红利行业 35 岁前 7.2%、传统私企 3.6%），并叠加**技能加成**（最高 +60%）、**信念加成**（信念>70 时 +5%）、**年龄乘数**（30-45 岁黄金期 ×1.2 → 46-51 岁 ×0.7 → ≥52 岁 ×0.5）、**经济周期**（萧条期 ×0.5）与职场意外。
- **All In 后（路径固化）**：改用"技能驱动 + 口碑复利 + 增长递减"逻辑，封顶为初始薪资 ×6。
- **年度封顶**：打工阶段单年涨幅 ≤25%，All In 后 ≤50%。

### 百分比投资（`pctInvestment`）

链上 / 理财等投资操作统一采用**百分比制**（按当前存款一定比例投入，回报也按比例），而非固定金额，从而让"选择真正造成差异"，避免"选与不选一样"。

### 总财富与财务自由

- **总财富** = 现金 + 房产 + 链上持仓 + 生科组合 + 店铺 + 被动收入 ×12。
- **财务自由判定**：满足任一即自由——① 被动收入 ≥ 年开销；② 可变现净资产 ≥ 年开销 × 20（4% 法则）。不硬绑"目标资产"数字。

## 六、命运岔路口

每条路径有 **3 个专属「命运岔路口」**（重大危机事件，如 AI 跃迁、交易所暴雷、监管铁拳），优先级 8-10、cooldown=999，保证打断正常流程且只触发一次；另有 6 个通用事件（优先级 4-6）。

**CrossroadPanel** 展示：标题（"第 X 岁 · 命运的岔路口"）、叙事正文（`{age}` 占位替换）、当前财务快照（存款 / 月薪 / 被动收入 / 房贷 / 养车）、年收入 / 支出 / 结余预估，以及 A/B/C/D 选项。选项会改变薪资、技能、信念、健康、压力、存款等；选项有前置条件，不满足则置灰。

## 七、退休与结局

### 退休机制（非强制）

**退休完全非强制**：玩家随时可以主动退休（`canRetireNow` 仅要求 `gamePhase === 'playing'`），无财富或路径成功门槛。退休按钮从一开始就亮着。

**三个硬终点**（唯一强制结束的条件）：
1. **破产**：可变现净资产 < -30 万，随时触发。
2. **中道崩殂**：健康 < 20。
3. **60 岁硬上限**：到龄强制结算，无论是否达标都判定结局。

### 结局评级系统（满分 100）

所有结局（路径 + 普通）共用一套评分口径：

| 维度 | 分值 |
|---|---|
| 财务成就 | 0-60（总财富 / 目标资产覆盖率） |
| 路径赌注 | 0-10（路径成功 +10） |
| 提前退休 | 0-10（越早越高，提前 ≥15 年 +10） |
| 生活圆满 | 0-30（幸福 + 健康 + 关系） |
| 生存底线 | 0-10（未破产 / 未重病 / 未长期失业） |

**评级边界**：S≥80 传奇、A≥65 优就、B≥50 安稳、C≥28 艰困、D<28 崩坏。

**结局类型**：路径专属结局（`path_success_*` / `path_failure_*`，需财务达标**且**路径事业真正走通）+ 普通结局 E1-E9（传奇自由人 / 温馨港湾 / 平凡微光 / 中道崩殂 / 极简行者 / 创业者之歌 / 体制内银发 / 转世再战 / 浮生半日闲）。

**结局画面流程**：延迟揭晓评级动画 → 展示结局文本 + 金句 → 退休第一天微型场景（按评级差异化）→ 人生图鉴 / **分享海报**（网易云风格年度人生报告，可下载 PNG）。

### 退休梦想与趣味报告

- **6 个退休梦想**（各含目标资产与换算道具）：环球旅行家🌍(800 万)、田园归隐🏡(300 万)、老年学霸📚(500 万)、终极宅神🎮(1000 万)、广场舞之王💃(500 万)、银发志愿者🤝(800 万)。每个梦想把"净资产能换多少"折算成有梗实体。
- **趣味报告**：数字人生卡片墙（购买力换算 + 一生数字标语）、18 个趣味成就徽章墙、身体损耗结算单（反套路体检报告，黑色幽默吐槽）、年度人生报告海报。

## 十、给 AI 的协作提示

- 所有**链上 / 投资持仓**操作必须使用百分比制（`pctInvestment` 等），并通过 `getChainHoldings(s)` 检查持仓 > 0 的前置条件。
- 叙事事件必须包含 `sceneTag` 字段以触发对应视觉；危机类事件需包含 `crisis` 以触发受击特效。
- 年度结算最显眼的叙事位置必须优先展示**选择触发的剧情**，黑天鹅（被动随机事件）与健康琐事不进入主事件候选池。
- 40 岁再分叉事件需设 `weight: 100` 确保高触发率（97.8%+）。
- 所有路径初始必须以**副业**形式起步，不改变职业、城市与薪资；迁城需用 `switchCity()` 正确应用城市系数。
- 音频规范：**无背景音乐（BGM）**，仅保留音效（SFX）。
